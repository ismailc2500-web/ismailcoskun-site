# Caption fonts (optional)

Burned-in subtitles use the font named by `SUBTITLE_FONT` (default `Arial`) or the
series setting *Caption font*. If that font is not installed on your system, drop
its `.ttf` / `.otf` file here — FFmpeg/libass loads fonts from this folder when
rendering. Bold, wide fonts (e.g. Montserrat ExtraBold, Anton, Bebas Neue — check
their licences) read best on phones.
